# ZZX.LOG

ZZX 的个人技术博客，关注推荐系统、广告算法、生成式 AI 与工程实践。

## 本地预览

不需要安装依赖：

```bash
python3 -m http.server 8000
```

访问 `http://localhost:8000`。

## 发布

仓库使用 GitHub Pages 从 `main` 分支根目录自动部署。合并到 `main` 后，GitHub 会自动更新网站。

用户主页仓库必须命名为 `zzxAnthony.github.io`，对应地址为：

```text
https://zzxanthony.github.io
```

## 修改内容

- 首页：`index.html`
- 全站样式：`assets/styles.css`
- 交互：`assets/app.js`
- 文章：`posts/`

## 自定义域名

购买域名后，在仓库 **Settings → Pages → Custom domain** 中配置。建议使用简短的 `zzx` 品牌域名；是否可用取决于域名注册商的实时结果。
