Recommendation as Generation：推荐系统开始生成内容

如果内容池里没有用户真正想看的视频，推荐系统能不能直接把它生成出来？

生成式 AI2026.07.2210 MIN READ

从“选什么”到“造什么”

传统推荐系统的边界由内容池决定。模型再懂用户，也只能从已有物品中找到相对匹配的结果。Recommendation-as-Generation（RaG）把输出空间从固定 item pool 扩展到了可生成内容空间。

用户行为与画像
→ 兴趣 Semantic ID
→ 视频生产指令
→ 视频 / 音频 / 特效生成
→ 真实反馈闭环

这不只是把推荐包装成生成，而是让推荐模型负责定义需求，让多模态生成系统完成供给。

工业闭环才是关键

生成一段视频并不难，难的是生成值得推荐的视频。系统必须同时处理兴趣预测、创意规划、工具调度、质量控制和反馈归因。最终的播放、互动和负反馈还要回流，继续约束兴趣建模与内容生成。

推荐模型决定“用户可能想看什么”，生成模型负责“把这个兴趣做成可消费的内容”。

为什么值得关注

  • 覆盖长尾需求：细粒度兴趣不必等待供给侧预先生产。
  • 内容与人群共同优化：表达风格、节奏和卖点都能因用户而异。
  • 重写系统边界：推荐不再只是分发层，而开始参与内容生产。

仍然困难的问题

真实系统还需要面对生成成本、内容安全、同质化、版权和探索偏差。尤其当曝光反馈同时训练推荐与生成模型时，系统很容易把短期点击误认为长期价值。因此，RaG 更像一个新系统范式的起点，而不是终点。
