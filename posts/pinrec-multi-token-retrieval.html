PinRec：多token生成式检索

分析多 Token 表示、稠密向量生成与大规模推荐检索服务之间的关系。

生成式推荐克西2026.05.284 MIN READ
知乎原文 ↗

0. 写在前面

OneRec 的核心问题是：

生成式模型能不能统一召回和排序，直接生成推荐 session？

而PinRec 的问题更工程化：

生成式召回能不能在 Pinterest 这种超大规模平台里稳定服务，
同时支持多业务目标、候选多样性和低延迟？

值得注意的是：PinRec 没有走 semantic ID 自回归生成路线。它不是让模型生成 这样的离散 item code，而是让 transformer 根据用户历史生成多个 dense item embedding，然后用 ANN/Faiss 去召回真实 Pins。

所以 PinRec 更像是：

用户行为序列 -> transformer 生成多个未来兴趣向量 -> ANN 检索 Pins -> 下游排序/融合

PinRec 在 Pinterest Homefeed、Search、Related Pins 三个主要场景上线，带来显著线上收益，Homefeed 中 PinRec-{MT, OC} 带来 +1.73% site-wide grid clicks、+3.33% Homefeed grid clicks、+0.55% time spent；S
